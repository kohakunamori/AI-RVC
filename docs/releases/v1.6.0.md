这次把 TelkNet 同源的翻唱更新同步到了独立版。

- 已有干声可以直接换声，结果保留输入和转换后人声两轨，方便试听对比。
- 改善转音和长歌曲拼接，保留模型原生精度；修复双索引角色包、首次模型准备和官方 UVR5 路线的问题。
- 中英文界面、多轨播放和原始 WAV 下载同步更新。提供 Windows / Linux 的 CPU、GPU 便携包，以及 CPU、CUDA 容器镜像。

下载所选版本的全部分卷，放在同一目录后解压；可用附带的 SHA-256 文件检查完整性。

## English

This release brings TelkNet's shared cover updates to the standalone app.

- Convert existing dry vocals directly, with separate input and converted tracks for comparison.
- Improve pitch transitions and long-song joins while preserving native model precision. Fix paired character indices, first-time model preparation and the official UVR5 route.
- Update both interface languages, multitrack playback and original WAV downloads. Windows/Linux CPU and GPU portable packages and CPU/CUDA container images are available.

Download every volume for your chosen package into one folder before extracting. The included SHA-256 files let you check that the download is complete.
