# AI-RVC Studio v2.0.0 — 原生桌面版 + RVC 实时变声

**发布时间：2026-10-29**

AI-RVC 从默认浏览器 WebUI 转为 **PySide6 原生桌面 GUI**。Windows / Linux 提供便携发行包（CPU 与 NVIDIA GPU 两种版本），无需另行安装 Python。

### 核心功能

- **AI 翻唱**：RVC v1/v2、Seed-VC、YingMusic-SVC、SoulX-Singer-SVC；支持完整歌曲与已分离干声、参考声线、音高、混响/去混响。
- **RVC 实时变声**：选择麦克风与输出声卡（可使用已安装的虚拟声卡）、本地声线 `.pth` / `.index`、RMVPE / FCPE / PM、采样率、推理块长、输出增益；采用后台推理队列与 SOLA 拼接。
- **统一模型管理**：共享兼容 Python 环境及缓存，支持独立环境覆盖，浏览本地 RVC 模型并指定翻唱/实时变声用途。
- 原生 GUI 不需要访问网页或启动 HTTP 服务器。仓库源码可使用 `python run.py --web` 进入兼容模式；**便携桌面包不承诺旧网页功能**。

### 下载与启动

GitHub Release 附件提供四组完整便携包：`AI-RVC-Windows-GPU-Portable`、`AI-RVC-Linux-GPU-Portable`，以及两种 CPU 备用包。请下载所选平台和版本的 **全部分卷 + 对应 SHA256SUMS**；在同一目录合并/解压分卷。Windows 运行 `AI-RVC-Windows-GPU.exe`；Linux 为解压后的 `AI-RVC-Linux-GPU`。

**GPU 便携包预置 CUDA 12.8 PyTorch/cuDNN/NVRTC 等用户态运行依赖、HuBERT/RMVPE 基础模型、默认分离模型和 FFmpeg**，不需要单独安装 CUDA Toolkit，但**仍需要合适版本的 NVIDIA 显卡驱动**。CPU 包不能使用 NVIDIA CUDA。**Linux 实时声卡功能还依赖发行版的 PortAudio 系统库**（例如 Ubuntu/Debian 安装 `libportaudio2`）；Qt 可能需要 `libegl1`/`libgl1`。目标角色 RVC 权重及零样本 SVC 专属权重/独立模型环境并非全部打包（体积与授权原因），仍需按需准备。

### 验收范围与限制

- Windows / Linux CI 检查原生 Qt 窗口、实时音频队列及基础推理契约。
- 发行流水线执行 PyInstaller 冻结程序冷/热缓存、音频处理、模型/FFmpeg/运行库和 CUDA NVRTC 编译检查、产物 SHA-256 清单核对。
- **无 NVIDIA GPU 的 GitHub 托管 CI 无法证明实际 50 系显卡兼容性、麦克风设备、虚拟声卡和端到端实时延迟**；这些需要用户设备进一步实测。
- 实时变声仅支持 RVC 模型，Seed-VC / YingMusic-SVC / SoulX-Singer-SVC 目前用于离线翻唱。
- 这是首个原生桌面主要发行版，建议把旧版安装及原始声线资产保留以便回滚。

详细使用说明：[原生桌面使用指南](../DESKTOP_STUDIO.md)。

## English

# AI-RVC Studio v2.0.0 — Native Desktop & Real-time RVC

**Release date: October 29, 2026**

AI-RVC now launches a **native PySide6 desktop application** rather than a browser by default. Windows and Linux portable packages are published in both NVIDIA GPU and CPU variants, without requiring a separate Python installation.

### Included features

- Offline AI covers using RVC v1/v2, Seed-VC, YingMusic-SVC, or SoulX-Singer-SVC; song/vocal modes, singer reference audio, pitch and optional cleanup.
- Live RVC microphone conversion with selectable input/output (including separately installed virtual audio interfaces), local `.pth` / `.index`, RMVPE/FCPE/PM, sample rate, buffered processing and SOLA alignment.
- Unified local model registry, compatible Python/cache sharing, and convenient local RVC model selection.
- No browser, WebView or local HTTP service required for the native application. The source repository retains `python run.py --web` compatibility; the frozen desktop portable package does not guarantee the old browser mode.

### CUDA and setup

GPU bundles include **CUDA 12.8-enabled PyTorch, cuDNN/NVRTC user-space libraries, the default HuBERT/RMVPE and separation resources, and FFmpeg**. On Linux, system packages such as `libportaudio2` (and potentially `libegl1`/`libgl1`) are needed for microphone audio and Qt. A compatible **NVIDIA GPU driver is still required**; CUDA Toolkit does not need to be installed separately. Zero-shot SVC third-party checkpoints and their separately configured environments are not all redistributed. Target RVC voice checkpoints must be imported separately.

Download **every archive volume and the matching SHA256SUMS** for one package variant, keep all parts together, and extract. Use the GPU variant for NVIDIA CUDA; CPU is a fallback.

### Verification caveat

CI validates native GUI startup, audio DSP, package integrity and offline CUDA NVRTC library compilation. Hosted CI **does not** certify live microphone latency, RTX 50-series inference, or virtual soundcard routing on physical hardware. Realtime conversion is RVC-only; other SVC models remain offline.
